# Pickel

**Images, without the pickle.**

Pickel is an image loading library for SwiftUI, designed for modern iOS applications and built with Swift concurrency.

The goal is to make remote image loading feel natural in SwiftUI while providing a reliable foundation for request management, caching, and image delivery.

## Requirements

- iOS 17+
- Swift
- Xcode with Swift Package Manager support
